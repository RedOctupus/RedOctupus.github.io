# Hongyu Zhang Portfolio Site

This folder contains the full static site used for the GitHub Pages version of Hongyu Zhang's portfolio.

Included files:
- `index.html`
- `styles.css`
- `script.js`
- `assets/`

How to maintain:
- Edit copy and structure in `script.js` and `index.html`
- Adjust theme and layout in `styles.css`
- Replace project images inside `assets/`

Deployment target:
- GitHub Pages
- Recommended public URL: `https://redoctupus.github.io/`

Notes:
- This is a plain static site with no build step
- English is the default language
- Chinese content is included in `script.js`
